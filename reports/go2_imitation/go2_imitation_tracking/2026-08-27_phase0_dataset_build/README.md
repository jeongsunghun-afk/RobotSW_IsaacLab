## 1. 카테고리 선별

### 포함 (15개)

| 부류 | 카테고리 | 유지 클립 |
|---|---|---|
| 핵심 보행 | `walk` 536, `run` 74, `trot` 42 | 652 |
| 보행 전이 | `sit_walk` 42, `stand_walk` 26, `run_walk` 14, `lie_walk` 6, `sit_trot` 4, `stand_trot` 2, `lie_trot` 2, `trot_sit` 2, `trot_lie` 2, `run_sit` 2 | 102 |

전이 카테고리를 넣은 이유: 논문 1의 핵심 주장이 **mode 간 transition** 이고,
VAE latent 가 보행 종류 사이를 잇는 경로를 학습하려면 그 구간이 데이터에 있어야 한다.

### 제외

| 대상 | 사유 |
|---|---|
| `stand` 862, `lie` 512, `sit` 458 및 그 전이 | 보행 아님 |
| `jump*` (64 + 전이) | root z 최대 3.52 m — 보행과 이질적 |
| **`spin` 13, `spin_sit` 5, `sit_spin` 1** | **아래 참조** |

### ★ `spin` 제외 — 근거가 바뀌었다

초기 계획은 회전 오독 결함(§2026-08-27 `motion_lib_rotation_fix`)을 피하려고 `spin` 제외를 검토했다.
**그 결함은 수정되었으므로 그 근거는 사라졌다.** 그러나 실측 결과 `spin` 은 다른 이유로 제외된다.

봉투 `vx ∈ [-0.5, 4.0]`, `|wz| ≤ 2.0` 기준 **클립 내부비율**:

| 카테고리 | 중앙값 | ≥0.90 인 클립 비율 |
|---|---|---|
| `walk` | 1.00 | 87% |
| `run` | 1.00 | 79% |
| `trot` | 1.00 | 100% |
| **`spin`** | **0.03** | **0%** |

`spin` 은 개가 제자리에서 `|wz|` **5~6.29 rad/s** 로 도는 동작이다.
클립의 97%가 봉투 밖이라 **부분 트리밍으로도 살릴 수 없고**, 애초에 로봇 추종 범위를 넘는다.

**대가**: 고yaw 커버리지의 주 공급원이 사라진다. 다만 `walk` 가 `|wz|` 최대 4.62 까지 갖고 있어
`|wz| ≤ 1.5` 명령 범위는 여전히 지지된다(§3 표 참조).

## 2. 필터링

```
1330 파싱 (실패 0)
  -> md5 dedup        1330 -> 1046   (중복 284, 21.3%)
  -> 봉투 필터        1046 ->  754   (제외 292)
       프레임 < 30        158개
       내부비율 < 0.90    134개
```

**★ 파일명 스키마 함정.** `[M_]D<n>_<seq>_<subj>_<take>_F<start>_F<end>_<idx>` 에서
`seq` 는 순수 숫자(`061`) 외에 **`ex03`, `047z`** 변형이 있다.
정규식을 `D\d+_\d+_` 로 쓰면 **35.6%(493/1384)가 조용히 누락**되고 세션 수가 46 → 26 으로 잘못 나온다.
빌더는 파싱 실패가 하나라도 있으면 **에러로 중단**한다.

**클립 단위 필터인 이유**: 프레임 단위로 잘라내면 시계열이 끊긴다.
VAE 는 **상태전이** `(x[t-1], x[t])` 를 학습하므로 연속성이 필수다.

봉투 밖으로 남은 프레임은 **2,065 / 140,130 = 1.47%** 이고, 내부비율 중앙값은 1.000 이다.
이 잔여분은 급선회 transient 같은 **실제 expert 거동**이라 제거하지 않았다.

| `|wz|` max | 클립 수 | 비율 |
|---|---|---|
| > 1.5 | 246 | 32.6% |
| > 2.0 | 147 | 19.5% |
| > 3.0 | 22 | 2.9% |
| > 4.0 | 4 | 0.5% |

## 3. bin × 세션 다양성 (진짜 게이트)

프레임 커버리지는 다양성을 보장하지 않는다. 각 칸의 값은 **기여 세션 수**(괄호는 프레임, 천 단위).

```
      vx \ wz     -1.5    -1.0    -0.5    +0.0    +0.5    +1.0
 [-0.5,+0.0)  12(  0k)  13(  0k)  28(  3k)  29(  3k)  14(  0k)  11(  0k)
 [+0.0,+0.5)  20(  2k)  25(  4k)  40( 12k)  39( 11k)  28(  3k)  21(  2k)
 [+0.5,+1.0)  16(  1k)  27(  3k)  36(  7k)  37(  7k)  28(  2k)  17(  1k)
 [+1.0,+1.5)   4(  0k)  15(  0k)  29(  2k)  28(  2k)  16(  0k)  13(  0k)
 [+1.5,+2.0)   3(  0k)   9(  0k)  18(  0k)  19(  0k)  10(  0k)   5(  0k)
 [+2.0,+2.5)   3(  0k)   6(  0k)  14(  0k)  15(  0k)   9(  0k)   2(  0k)
 [+2.5,+3.0)   2(  0k)   3(  0k)  11(  0k)  10(  0k)   7(  0k)   2(  0k)
 [+3.0,+3.5)   0(  0k)   1(  0k)   9(  0k)   9(  0k)   2(  0k)   0(  0k)
 [+3.5,+4.0)   0(  0k)   1(  0k)   4(  0k)   4(  0k)   1(  0k)   0(  0k)
```

채움 **50/54**, 세션 ≥3 인 bin **43/54**.

### 권고 명령 범위

**`vx ∈ [-0.5, 3.0]`, `|wz| ≤ 1.5`.**

| 판단 | 근거 |
|---|---|
| 하한 -0.5 | `vx < -0.5` 는 기여 세션이 0~2 개다. 후진은 개 mocap 에 거의 없다 |
| 상한 3.0 | `vx > 3.0` 의 극단 yaw bin 은 세션 0~2 개 |
| `\|wz\| ≤ 1.5` | `spin` 제외로 고yaw 전담 소스가 없고, `walk` 가 지지하는 범위가 여기까지 |

**★ 반드시 문서화할 한계**: `vx > 2.0` 과 `|wz| > 1.0` 이 **겹치는** 영역은
기여 세션이 **2~9개**로 얇다. 이 영역에서 나중에 실패가 나오면
**설계 탓인지 데이터 탓인지 분리할 수 없다.** 판정 시 이 표를 함께 볼 것.

## 7. 다음 단계 (Phase 1)

Motion Encoder 오프라인 학습. 게이트는 두 가지이며, **§4 의 세션 단위 split 이 전제**다.

| 게이트 | 방법 | 통과 기준 |
|---|---|---|
| G1 | **leave-one-session-out** 재구성 | held-out 오차 ≤ in-sample 오차 × 2 |
| G2 | latent 보간 단조성 | 같은 mode·다른 속도 두 클립의 `z` 보간 시 `vx` 단조 증가 |

t-SNE 군집은 **게이트가 아니다** — 클립 정체성만으로 갈리므로 항상 통과한다.
