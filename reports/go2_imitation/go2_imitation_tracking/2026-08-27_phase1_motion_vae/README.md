# Phase 1 — Motion VAE 오프라인 학습 · **미통과**

2026-08-27 · 브랜치 `isaac-6.0`
학습 `scripts/imitation_learning/train_go2_motion_vae.py` · 평가 `scripts/imitation_learning/eval_go2_motion_vae.py`

---

## 결론

논문 1 §V 의 상태전이 VAE 를 구현했고, **인코더는 잘 학습됐지만 디코더가 `z` 를 읽지 않는다.**
Gaussian latent 로는 posterior collapse 를 넘지 못했다. **Phase 2 로 넘어가면 안 된다.**

| 게이트 | 값 | 기준 | 판정 |
|---|---|---|---|
| G1 held-out 세션 재구성 | 1.39 ~ 1.61× | ≤ 2.0× | PASS |
| **G2a** 선형 프로브 `z → 클립 vx` (LOO CV) | **R² 0.83 ~ 0.95** | ≥ 0.5 | **PASS** — 인코더는 정상 |
| **G2b** 보간 **효과 크기** | **0.1 ~ 3.0%** | ≥ 10% | **FAIL** — 디코더가 무시 |
| G0 셔플 (진단) | 1.05 ~ 1.45× | — | collapse 시사 |

**핵심 수치**: 클립 A, B 의 평균 속도가 **1.0~1.2 m/s** 차이 나는데,
그 `z` 를 보간해 한 스텝 디코드하면 예측 `vx` 는 **0.001~0.004 m/s** 만 변한다.

## 1. 구현

```
encoder : (x[t-1], x[t])  ->  q(z|·)     Gaussian, latent 18-D, FC 2x256 ELU
decoder : (x[t-1], z)     ->  x_hat[t]   MoE expert 6개 (각 FC 2x256) + gating FC 2x64
loss    : ||x[t]-x_hat[t]||^2 + beta*KL,  beta = 0.05,  free_bits 0.02/dim
일정    : teacher forcing 20 ep -> autoregressive 60 ep
```

`x_vae` 49-D (논문과 동일): base height 1 + heading-relative 6D 회전 6 + 선속도 3 +
각속도 3 + 발위치 12 + 관절각 12 + 관절속도 12.
회전에서 yaw 를 제거해 latent 이 진행 방향에 불변하다.

데이터는 Phase 0 산출물 754 클립. train/val 은 **세션 단위**, 정규화 통계는 **train 에서만**.
파라미터 684,048. 학습 12~15초.

## 2. 진단 — posterior collapse

첫 학습에서 KL 이 내내 `free_bits × 18 = 0.36` 에 고정됐다. **KL 페널티가 작동조차 안 하는데도**
`z` 를 안 쓴다는 뜻이다. 즉 β 문제가 아니다.

| 조건 | 재구성 MSE | 배율 |
|---|---|---|
| `z` = encoder | 0.007732 | 기준 |
| `z` = 0 | 0.008076 | 1.04× |
| `z` 셔플 | 0.008142 | 1.05× |
| (대조) `x_hat = x_prev` | 0.025228 | 3.26× |

**원인**: `x[t]` 가 `x[t-1]` 로부터 거의 결정적이다. 60fps 에서 `x ≈ x + v·dt` 로 외삽되고,
속도를 빼도 **관절 자세 자체가 보행 위상과 속도를 담고 있다**.

### 처방 전수 시도 — 전부 부족

| 처방 | 설정 | G0 셔플 | G2a R² | **G2b 효과** |
|---|---|---|---|---|
| 없음 | stride 1 | 1.04× | 0.938 | 0.1% |
| 서브샘플 | stride 2 (30fps) | 1.05× | 0.931 | **0.1%** |
| 서브샘플 | stride 3 (20fps) | 1.07× | — | — |
| 조건 dropout | stride 2, cd 0.3 | 1.44× | 0.941 | 0.5% |
| 조건 dropout | stride 2, cd 0.5 | 1.45× | 0.947 | **3.0%** |
| **속도블록 dropout** | stride 2, vd 0.5 | 1.11× | 0.908 | 1.3% |
| **속도블록 dropout** | stride 2, vd 0.8 | 1.14× | 0.829 | 0.7% |
| **속도블록 dropout** | stride 2, vd 1.0 (속도 완전 차단) | 1.16× | 0.891 | **2.1%** |

최고가 `cond_dropout 0.5` 의 **3.0%** 로, 기준 10% 에 크게 못 미친다.
**속도를 디코더에 아예 주지 않아도 2.1%** 라는 것이 결정적이다 —
외삽 지름길을 끊어도 자세만으로 다음 자세가 정해진다.

## 3. ★ 게이트 설계에서 두 번 틀렸고, 두 번 다 정정했다

이 절이 이 보고서에서 가장 중요하다. **두 번 다 "통과했다"는 잘못된 결론을 냈었다.**

### (1) `z` 고정 장기 롤아웃은 분포 밖이다 — 초안 G2 폐기

초안 G2 는 `z` 를 60스텝 고정해 롤아웃하고 평균 속도를 쟀다. 전 설정 FAIL 이었고
속도가 원본(0.38~0.90 m/s)보다 낮은 0.11~0.42 m/s 로 수렴했다.
그러나 논문 1의 synthesis 정책은 **매 스텝 새 `z` 를 출력**하므로, `z` 고정은
모델이 학습된 적 없는 사용법이다. → one-step 지표로 교체했다.

### (2) 순위상관만 보면 안 된다 — 효과 크기 필수

교체한 one-step G2b 가 Spearman **+1.000 / 100%** 를 내서 "PASS" 로 판정했었다.
값을 보니 예측 `vx` 변화폭이 **0.001~0.004 m/s**, A-B 간격 대비 **0.1%** 였다.
**무시할 만한 차이 위의 순위 아티팩트**였고, `trot` 의 ρ = −1.000 도 같은 이유의 잡음이었다.
→ **효과 크기(변화폭 / A-B 간격) ≥ 10%** 를 판정 조건에 추가했다.

### (3) 부수 정정 — 선형 프로브의 미결정계

`run`/`trot` 의 G2a R² 가 1.000 으로 나왔는데, 클립 16개에 latent 18차원이라
**항상 1.0 이 나오는 미결정계**였다. → **leave-one-out 교차검증**으로 교체했다.
LOO 기준 실제 값은 0.83~0.95 이고, 이건 진짜다.

### (4) G0 은 강등했다가 복권했다

G0(셔플)을 "스텝 단위라 부적절"하다며 진단용으로 강등했으나,
효과 크기를 재고 나니 **G0 이 처음부터 옳은 신호**였다. G2a(인코더)와 G0(디코더)이
서로 다른 것을 재고 있었을 뿐이다.

> **교훈: 인코더가 정보를 담는 것과 디코더가 그것을 쓰는 것은 별개다.**
> 생성 모델의 latent 을 판정하려면 **디코더 민감도**를 효과 크기로 재야 한다.

## 4. val split 층화 — 부수 개선 (완료)

초기 무작위 split 은 walk 편중이라 `run`(4클립)·`trot`(2클립) 게이트를 돌릴 수 없었다.
빌더에 `--split_mode stratified` 를 추가해 카테고리별 속도 간격을 확보했다.

| 카테고리 | val 클립 | vx 범위 | 간격 |
|---|---|---|---|
| walk | 121 | 0.01 ~ 1.23 | 1.23 |
| run | 16 | 1.47 ~ 2.53 | 1.06 |
| trot | 16 | 1.07 ~ 2.21 | 1.14 |

세션 43개 중 19개가 여러 카테고리에 걸쳐 있어 카테고리별 분리 배정은 불가능하다.
대신 각 카테고리의 속도 간격을 만족하도록 세션을 탐욕적으로 고른다.
val 8세션 / train 35세션. `metrics/session_split.json`

## 5. 다음 — vMF latent 이 유력한 처방이다

논문 1은 latent 을 **von Mises-Fisher (hypersphere)** 로 둔다. 논문은 이유를
"synthesis 정책의 액션 공간을 유계로 만들기 위해"라고 쓰지만,
**collapse 방지 기전이기도 하다**:

| | Gaussian (현재) | vMF |
|---|---|---|
| KL | `q → p` 로 붕괴 가능 (실제로 붕괴함) | κ 고정 시 방향에 **무관한 상수** → 붕괴 압력 없음 |
| `z` 의 크기 | 0 으로 수축 가능 | **항상 단위 벡터** — 디코더가 잡음으로 무시할 수 없음 |

논문이 "이것 없이는 스타일 일관성을 잃거나 **gait mode 를 재현하지 못한다**"고
명시한 것도 이와 부합한다.

**권고**: Phase 3 로 미뤄 뒀던 vMF 전환을 **앞당겨 Phase 1에서 시도**한다.
구현은 `nicola-decao/s-vae-pytorch`(MIT)의 vMF 분포·rejection 샘플러를 이식한다.
VAE 재학습이 15초라 반복 비용은 없다.

차선책(vMF 도 실패할 경우):

| 대안 | 내용 |
|---|---|
| 다중 스텝 예측 | `x[t-1], z → x[t+k]` 로 예측 지평을 늘려 `z` 의 필요성을 키운다 |
| VQ-VAE | 이산 코드북은 구조상 무시가 불가능하다 (단 연속 명령과 궁합 나쁨 — 계획서 §5 C안) |
| 안 B 로 후퇴 | latent 을 **생성**이 아니라 **스타일 채점**에만 쓴다. 인코더는 이미 통과했으므로(G2a) 그대로 쓸 수 있다 |

**마지막 항목이 중요하다** — 계획서의 안 B 는 디코더를 쓰지 않으므로
이 blocker 의 영향을 받지 않는다. vMF 가 실패하면 안 B 가 살아 있는 퇴로다.
