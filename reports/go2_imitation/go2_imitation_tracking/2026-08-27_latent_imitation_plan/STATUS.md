### 1-3. Phase 1 — 무엇이 뚫렸고 무엇이 막혔나

**뚫린 것: posterior collapse.**

| 처방 | walk 보간 효과크기 |
|---|---|
| 기준선 (Gaussian) | 0.1% |
| 다중스텝 단독 (`pa3_gauss`) | 1.2% |
| **vMF 고정 κ=10 단독** | **12.0%** |
| **vMF + 다중스텝 (`pa3_vmf10`)** | **23.3%** (5/5 시드) |

기여는 비대칭이다 — vMF 가 거의 다 하고(100배) 다중스텝이 2배로 키운다.
기전은 **"KL 압력 제거 + 낮은 잡음"** 이다. "z 가 단위벡터라 무시 불가" 는 **틀린 설명**이었다
(구 없는 `gaussfix_b0` 가 22.5% 를 낸다).

**막힌 것: 속도축이 gait 카테고리마다 반정렬.**

`walk` 로 적합한 속도 프로브를 다른 gait 에 적용하면:

| 계열 | → run | → trot |
|---|---|---|
| vMF 전부 | −0.11 ~ −0.39 | **−0.71 ~ −0.82** |
| β=0 Gaussian 전부 | +0.77 ~ +0.90 | +0.93 ~ +0.95 |

vMF 설정 **37/37 run 평가에서 rho 음수**. 즉 "속도를 올리는 latent 방향" 이 walk 밖에서
통하지 않고 trot 에서 뒤집힌다. **synthesis 정책이 전 명령 범위를 일관되게 조종할 수 없다.**

## 2. 시도했고 실패한 처방 (반복 금지)

| 처방 | 결과 | 왜 실패했나 |
|---|---|---|
| 서브샘플 (stride 2/3) | 효과 0.1% | 자세만으로 다음 자세가 정해짐 |
| 조건 dropout 0.3/0.5 | 3.0% | 부분 개선, 기준 미달 |
| 속도블록 dropout 0.5~1.0 | 2.1% | **속도를 아예 안 줘도** 부족 |
| **카테고리/세션 균형 샘플링** | 축 안 움직임 | **같은 불균형 데이터로 전역 축을 만드는 반례(`gaussfix_b0`)가 존재** |
| **축 정렬 손실** (λ 스윕, step/clip/balanced) | 부호는 +1.00 로 고쳐짐, **크기 미달** | 교환 곡선. λ↑ → walk 효과 23.3 → 4.5% 단조 감소 |
| **`gaussfix_b0` 정규화** (6축 173 run) | 트레이드오프 미해소 | `G1` 을 내리는 축은 전부 `val_rec` 을 올림 |
| **안 B 스텝 보상** | AUROC **0.055** | 정지가 expert 보다 높은 점수 — exploit 확인 |

### 프론티어 (더 짜낼 것 없음의 증거)

`spbal_pa3` (λ=1.0, 균형은 보조손실에만): 전 카테고리 rho 양수 + walk 3/3 PASS 를
**동시에 만족한 유일한 arm** 인데 run 4.2% / trot 9.0% 로 미달.
양옆이 프론티어를 확정한다 — λ=0.1 은 walk 지키고 부호 잃음, λ=10 은 부호 지키고 walk 잃음.

## 3. 안 B (스타일 채점) 의 현재 위치

디코더를 쓰지 않으므로 **§1-3 의 축 문제 영향을 받지 않는다.**

| 항목 | 결과 |
|---|---|
| 스텝 로그밀도 보상 | **FAIL** — 정지 AUROC 0.055 (부호 반전) |
| 발산도 교체 (마할라노비스/k-NN) | 같은 반전 — 축이 아님 |
| **배치 marginal KL** | **정지 반전 해소** (static 1.000, stand 0.977), 8쌍 창까지 유지 |
| 시간축 파괴 탐지 | 강함 (셔플 0.998, 2배속 0.988). raw `x_vae` baseline 은 0.50 |
| **미세 gait** | **실명** (좌우 교환 0.55, 위상분리 0.52~0.57) — 창 길이 무관 |

★ **배치 전체에 같은 상수를 주면 PPO advantage 에서 value baseline 에 흡수되어
정책 gradient 기여가 0 이다.** env 별 시간창으로 개별화해야 한다.

★ 미세 gait 실명의 원인은 **인코더 입력이 한 스텝 전이**라 보행 위상을 못 보는 것.
이는 안 A 를 살린 `predict_ahead` 와 **같은 진단**이다.

## 4. ★★ 방법론 — 게이트가 네 번 틀렸다

이 세션의 가장 이전 가능한 산출이다. 앞으로 이 프로젝트의 모든 판정에 적용한다.

| # | 틀린 게이트 | 어떻게 드러났나 | 교정 |
|---|---|---|---|
| 1 | t-SNE 군집 분리 | 클립 정체성만으로 갈려 **항상 통과** | 폐기, 시각화로만 |
| 2 | `z` 고정 장기 롤아웃 | 모델이 학습된 적 없는 **분포 밖 사용** (정책은 매 스텝 새 z 를 낸다) | one-step 지표로 교체 |
| 3 | Spearman 단독 | ±1.000 인데 실제 변화폭이 **0.001 m/s (0.1%)** — 순위 아티팩트 | **효과 크기 ≥10%** 병기 |
| 4 | 선형 프로브 in-sample R² | 클립 16 vs latent 18 = **미결정계, 항상 1.0** | LOO 교차검증 |
| 5 | **전이 상관** (축 정렬 arm 한정) | 손실 함수와 **같은 함수 형태** → 순환 | `L_speed` arm 에서는 판정 제외 |
| 6 | **`G1` 비율 게이트** | **모델을 망가뜨려 통과 가능** | **절대 `val_rec` / `gap` 으로 교체 필요** |

### 6번이 아직 미적용이다 — 이것이 다음 작업의 출발점

```
G1 = val_rec / train_rec

인코더 잡음을 키우면 두 항이 함께 오르는데 train_rec 이 더 빨리 올라 비율은 내려간다.
  base   : 0.00184 / 0.00090 = 2.04   <- "탈락"
  ne0.40 : 0.01010 / 0.00605 = 1.67   <- "통과", 그러나 모델은 5.5배 나쁘다
gap = val_rec - train_rec 은 반대로 +331% 악화
```

같은 예측 지평(stride 2, k 1) 안에서:

| 설정 | `val_rec` | `gap` | `G1` | 현행 판정 |
|---|---|---|---|---|
| `regress_gauss` | 0.02708 | 0.00994 | 1.580 | PASS |
| `vmf_k10` | 0.01726 | 0.00583 | 1.509 | PASS |
| **`gaussfix_b0`** | **0.00184** | **0.00094** | 2.04 | **FAIL** |

**held-out 절대오차가 가장 작고 일반화 격차도 가장 작은 모델이 유일하게 탈락한다.**
"`gaussfix_b0` 는 일반화가 나쁘다" 는 서술은 틀렸고 "in-sample 이 유난히 좋다" 가 맞다.

### 7번 — 3 시드로는 판정할 수 없다

| 지표 | 3 시드 (판정에 쓰였던 값) | 10 시드 |
|---|---|---|
| `gaussfix_b0` `G1` | 2.01 | **2.04 [1.84 ~ 2.23]** |
| `gaussfix_b0` 전이 →run | +0.90 | **+0.72 [−0.41 ~ +0.95]**, 3/10 이 +0.5 미만 |

"β=0 Gaussian 만 전역 축을 갖는다" 는 **10 시드 중 7 개의 진술**이다.
VAE 학습 1 run 이 20 초다. **최소 10 시드**로 판정한다.

## 6. 앞으로의 계획

### 원칙

1. **게이트를 먼저 고치고 재판정한다.** 새 방법을 시도하기 전에.
   §4-6 이 보인 대로 현재 결론 일부는 잘못된 게이트 위에 있다.
2. **최소 10 시드.** 1 run 이 20 초다. 3 시드 판정은 두 번 뒤집혔다.
3. **판정은 디코더 민감도(G2b) 단독.** 인코더 지표는 손실과 순환할 수 있다.
4. 실패는 실패로 기록한다. 유리한 지표·시드를 고르지 않는다.

### Step 1 — 게이트 교체와 전면 재판정 (선행, 반나절)

| 작업 | 내용 |
|---|---|
| 1-1 | `G1` 을 **절대 지표**로 교체: `val_rec <= 기준 × C` 와 `gap` 병기. 예측 지평이 다르면 비교 금지를 코드로 강제 |
| 1-2 | 주요 후보 **10 시드 재판정**: `pa3_vmf10`, `st1_pa3_vmf10`, `gaussfix_b0`, `spbal_pa3` |
| 1-3 | 결과에 따라 §1-3 / §2 의 결론 갱신 |

**게이트가 바뀌면 `gaussfix_b0` 의 지위가 달라진다.** 지금 유일한 결격 사유가 비율 게이트인데
그게 무효라면, 이미 전역 축(부분적)과 walk 효과 22.5% 를 가진 후보가 살아난다.
축 정렬 손실 arm 도 재평가 대상이다(λ 전 구간에서 `val_rec` +40~62% 인데 `G1` 은 안 움직였다).

### Step 2 — 분기 (Step 1 결과에 따라)

| 조건 | 다음 |
|---|---|
| `gaussfix_b0` 계열이 새 게이트를 통과 | 그 계열로 Phase 2 진입. vMF 는 폐기 |
| 통과하지 못함 | **속도 조건부 인코더** — `z` 에 속도를 담지 않고 `(z, v_cmd)` 를 디코더에 준다. 축 문제를 **우회**하는 유일한 미시도 구조 변경 |
| 둘 다 실패 | **안 B 로 전환**(§3) 또는 **저속 전용 확정** |

### Step 3 — 안 B 병행 트랙 (Step 1·2 와 독립)

안 B 는 디코더를 안 쓰므로 축 문제와 무관하다. 남은 두 과제:

| # | 작업 | 근거 |
|---|---|---|
| 3-1 | **인코더 입력 창 확대 재학습** (`w = 10`) | 미세 gait 실명의 구조적 원인이 한 스텝 전이. 계획서 원안이기도 하다. 재학습 15초 |
| 3-2 | **env 별 시간창 `D_marg`** 설계 | 배치 상수는 gradient 기여 0. 8쌍 창까지 유지됨이 실측됨 |

3-1 은 **안 A 에도 도움이 될 수 있다** — `predict_ahead` 와 같은 진단(한 스텝으로는 부족)이다.

### Step 4 — AMP arm 마무리 (독립)

| 작업 | 내용 |
