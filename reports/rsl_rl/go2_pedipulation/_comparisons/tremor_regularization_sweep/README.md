### 구조적 결함

`p_action_rate` 는 두 경로에서 **다른 물리량**을 벌하고 있었다.

- 지지 다리: `a_loc` 가 위치 → `Δa` 는 속도 → 속도 페널티 ✅
- 조작 다리: `a_man` 이 이미 증분 → `Δa` 는 **가속도** → **1차 페널티 없음** ❌

`a_man` 이 0 이 아닌 상수로 유지되는 목표 표류의 비용이 **정확히 0** 이었다. 그리고
`_prev_joint_target` 버퍼는 유지만 되고 **어떤 보상 항에도 쓰이지 않고 있었다.**

## 판정 — `jtr40_jvf` 채택

떨림 −50%(2.827 → 1.415)이면서 push 는 base 대비 유지(150 N −1.9%p 로 오차범위 내, 200 N
+5.6%p, 300 N +9.9%p), 궤적 RMSE 는 **개선**(21.73 → 19.72 mm), hold 오차도 개선
(16.11 → 15.60 mm). 생존률만 100 → 98.7% 로 소폭 하락.

## 읽어낸 것

1. **지지 다리는 진단대로 고쳐졌다.** 2.17 → 0.86 (−60%). "1차 페널티 부재"가 실제 원인.
2. **필터는 떨림이 아니라 push 를 샀다.** `jvf_only` 는 떨림 −5% 인데 200 N +22.0%p, 추종
   비용 0. SNR 이 올라가자 정책이 그 이득을 **매끄러움이 아니라 성능에 썼다** — 목적함수에
   매끄러움 가격이 낮으면 합리적인 선택이다. 필터와 페널티는 **같은 손잡이를 반대로** 돌린다.
3. **규제↔강건성 상충은 근본적이지 않았다.** 입력 SNR 문제였고, 필터가 번 여유를 페널티로
   환전하면 둘 다 얻는다.
4. **분포 불일치 가설은 기각.** `mix`(정지 목표 40% 혼합)는 2.078 로 `jtr10_jvf`(1.991)와
   구분되지 않는다.
5. **조작 다리에 별도 기전이 남아 있다고 적었던 것은 이후 DR ablation 으로 정정됐다** —
   별도 기전이 아니라 노이즈 감도가 높았을 뿐이다. 노이즈를 끄면 3.09 → 0.02 로 사라진다.
   [`../../2026-07-31_09-31-33_jtr40_jvf/README.md`](../../2026-07-31_09-31-33_jtr40_jvf/README.md) 참조.

## 지표 정정 두 건

- **"랜덤워크라 EMA 는 답이 아니다"는 틀렸다.** Δtarget 부호 반전율(0.49)만 보고 내린
  결론이었다. MSD/lag 를 재니 `k=1:0.023 k=2:0.033 k=4:0.044 k=8:0.033 k=16:0.007 k=64:0.002`
  로 **큰 lag 에서 감소** — 유계 평균회귀다. action lag-1 자기상관 0.60~0.89, 상관시간
  2~9 step (2.5~12 Hz). EMA 가 깎을 수 있는 대역이라 `action_filter_alpha` arm 을 추가했다.
- **`foot_pos_std` 는 떨림 지표가 아니다.** 저주파 표류가 섞인다. 떨림은
  `joint_target_jitter` / `jvel_rms` 로 읽어야 한다.

## 계측 추가

`play_pedipulation_gates.py` 에 이 비교를 위해 넣은 것들.

- `--zero_noise {joint_pos,joint_vel,gravity,foot_pos,bias}` — 채널별 노이즈 ablation.
  집계 3-way 로는 어느 채널인지 못 가른다.
- 떨림의 **경로별 분해** (`jitter_manip` / `jitter_supp`) — 두 경로는 구조가 달라 섞으면 안 된다.
- `delta_sign_flip_rate`, `act_lag1_autocorr`, `act_msd_per_lag` — 고주파 chatter / 랜덤워크 /
  평균회귀를 구분한다.
- `--jvel_filter_alpha`, `--action_filter_alpha` — **학습 때 값과 반드시 일치**해야 한다.
- `--video_zoom` — 발끝 수 mm 의 떨림은 전신 뷰로 육안 판별이 안 된다.
