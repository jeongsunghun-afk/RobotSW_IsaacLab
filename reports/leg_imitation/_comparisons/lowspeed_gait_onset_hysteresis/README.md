## 결론

저속 실패는 **"0.5 m/s를 못 낸다"가 아니라 "정지 상태에서 보행으로 진입을 못 한다"** 이다.

같은 정책이 같은 명령(0.5 m/s)을 받는데, 램프 **상승** 구간(정지에서 출발)에서는 1~64%,
**하강** 구간(4.0에서 내려와 이미 걷는 중)에서는 **61~77%** 를 낸다. 하강은 측정한 7개 run 전부에서
안정적이고 duty(보행 중인 스텝 비율)가 예외 없이 **1.00** 이다.

![상승 vs 하강](figures/gait_onset_hysteresis.png)

## 근거

### 1. 접근 방향만 다른데 결과가 갈린다

| run | 상승 duty | 상승 달성 | 하강 duty | 하강 달성 |
|---|---|---|---|---|
| 8k | 0.84 | 64% | 1.00 | 74% |
| 15k | 0.74 | 33% | 1.00 | 71% |
| 25k | **0.06** | **1%** | 0.98 | 61% |
| 40k | 0.46 | 18% | 1.00 | 77% |
| 50k | 0.43 | 30% | 1.00 | 70% |
| ds14 (length 가중치) | 0.64 | 44% | 0.99 | 62% |
| wcmd (ds18) | 0.75 | 57% | 1.00 | 66% |

`duty` = hold 구간에서 순간 `|jvel| RMS > 0.4` 인 스텝의 비율. 1.0이면 연속 보행, 0이면 정지 자세 유지.

### 2. 실패는 "느리게 걷기"가 아니라 "안 걷기"다

상승 0.5 구간을 롤아웃 단위로 보면 duty와 달성률이 함께 움직인다.

```
50k    66%(duty 0.99)    0%(duty 0.09)    1%(duty 0.00)   59%(duty 0.77)
25k    -1%(duty 0.03)    1%(duty 0.00)    2%(duty 0.09)    7%(duty 0.43)
 8k    68%(duty 1.00)   68%(duty 0.94)    8%(duty 0.09)   60%(duty 0.75)
```

50k와 8k는 걷는 롤아웃(duty ≈ 1, 60~68%)과 서 있는 롤아웃(duty ≈ 0, 0~8%)으로 갈린다.
25k는 4개 전부 정지 쪽에 갇혔다. 40k는 duty 0.42~0.65의 중간대가 있어 완전한 이봉은 아니다.

### 3. 데이터셋 커버리지·가중치 방식은 원인이 아니다

데이터셋(ds14) 클립 속도는 0.05 ~ 3.01 m/s이고 저속 쪽에 `leg_walk1_stmr`(0.44 m/s),
`leg_walk`(0.17), `leg_walk_stmr`(0.10) 등이 있다.

원인 배제의 근거는 커버리지 자체가 아니라 **하강 구간이 성공한다**는 사실이다. 정책 레퍼토리에
0.5 m/s 걸음이 없다면 하강에서도 실패해야 하는데, 하강은 `length` 가중치 run과 `ds18` run을 포함해
**전부** 61~77%를 낸다. 따라서 가중치 방식(`command_uniform` vs `length`)도, 클립 구성도 1차 원인이 아니다.

이는 `project_go2_tracking_cannot_start_from_rest`(RSI로 0/62 → 44/58 개선했으나 정지 스폰은 28.1%에
머무름)와 같은 계열의 문제로 보인다.

## 정정

- 이전에 "cmd 0.5가 25k 1% → 40k 18% → 50k 30%로 단조 붕괴"라고 한 것은 틀렸다. 단조가 아니라
  **롤아웃 간 분산이 큰 구간**이며, 25k가 최저점이고 이후 회복한다.
- 이전에 "걷기 시작하는 건 cmd 0.88부터"라고 한 것은 25k 롤아웃 1 하나의 관찰이었다. 집계하면
  대부분의 롤아웃은 cmd 0.5에서 이미 다리를 움직인다.
- 체크포인트 순위 해석 주의: `ramp_summary.py`의 `per_rollout`은 `range(1, n_up)`으로 **상승만**
  집계한다. 따라서 평균 달성률은 "정지에서 가속하는 능력"이고, 8k가 82.5%로 25k(71.1%)를 앞선 것은
  거의 전적으로 cmd 0.5 한 점 때문이다. 정상 주행(2.0~4.0)과 쏠림에서는 25k·50k가 동등하거나 낫다.
