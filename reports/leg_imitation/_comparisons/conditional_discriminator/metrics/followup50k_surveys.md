## 1. 요약 표

정지 출발(`--all_stand`) 기준. `상향`·`하향` 은 에피소드 중 명령 변경 전후로 걸음이 실제로 바뀐 비율(바뀌어야 할 표본 대비).
`|Δvx|` 는 클립 속도를 명령으로 준 프로브의 |실측 − 명령| [m/s] (고속 = `leg_run1` 2.854, 저속 = `leg_walk1` 0.935).

## 3'. `other` 라벨과 분모 — 두 가지 확인

`gait_survey_analyze.py` 는 라벨을 두 단계로 만든다. thigh 위상 기울기로 잰 stride 주파수가 2 s 창에서
3 사이클에 못 미치면 `-` 로 두고 **분모에서 통째로 뺀다**. 창을 채운 표본 중 위상 패턴이
trot/pace/bound/gallop/pronk 어디에도 안 맞으면 `other` 다. 둘은 다른 것이다.

**(1) 분모.** `-` 로 빠지는 비율은 저속(cmd 0.5~1.5)에서 다섯 run 모두 63~75% 다
(A' 74.9 · B' 71.7 · (a) 63.2 · (b) 67.1 · (c) 69.9). 즉 저속 열은 어느 run 이든 표본의 1/3 만 본 값이다.
게다가 저속 `gallop` 의 실제 표본 수는 A' 1 · B' 6 · (a) 3 · (b) 9 · (c) 4 개다.
**저속 gallop% 열은 run 간 비교에 쓰지 마라.** 고속 열은 `-` 배제 후 n 이 823~893 이라 이 문제가 없다.

**(2) `other` 가 떨림 아티팩트인가.** 같은 run·같은 속도 bin 안에서 라벨별로 FL thigh 신호의
8~25 Hz 파워 비율과 stride 주파수를 쟀다.

**결론은 갈린다.** 저속에서 σ 가 큰 세 run(B'·(b)·(c))은 `other` 의 thigh HF 가 `pace` 의 2.2~2.5배다.
그러나 A' 와 (a) 에서는 방향이 뒤집히거나 미미하고, 고속에서는 `other` 와 `gallop` 의 HF 가 거의 같다
(0.021 vs 0.019 · 0.030 vs 0.030 · 0.026 vs 0.025). stride 주파수와 진폭은 라벨 간 차이가 없다.
`other` 열이 떨림을 재고 있다는 것도, 순수한 거동 차이라는 것도 **이 데이터로는 확정할 수 없다**.
아래 관찰 5 는 이 불확정성을 안고 읽어야 한다.

## 4. 관찰

1. **(a) 는 떨림을 절반쯤 줄였다. 없애지 못했다.** 8~25 Hz 비율이 B' 45k 0.42~0.67 → (a) 0.19~0.25 로 내려왔지만
   A' 의 0.03~0.11 위에 남아 있다. 참조 대비 거리는 클립마다 다르다 — `leg_run1`(2.85 m/s) 0.247 vs 참조 0.199 로
   거의 동률인 반면, `leg_trot0` 은 0.190 vs 0.042 로 4.5배, 절대 파워로도 40.9 vs 8.9 로 4.6배다.
   `leg_trot0` 이 최악의 클립이다. 참조 `dof_vel` 은 60 Hz 유한차분이라 고주파가 부풀려져 있으므로
   (`gap_spectral.md` 기재), (a) 와 참조의 실제 격차는 이 표보다 **클** 수 있다.
2. **B' 의 장점(자세·발 근접)은 (a) 에서 유지된다.** `dof_pos` W1 0.0468 · `foot_pos` 0.0166 으로 다섯 run 중 가장 작고,
   `dof_vel` W1 은 B' 1.26 → (a) 0.68 로 A'(0.46) 쪽으로 이동했다.
3. **(a) 는 gait 선택성과 상향 전환을 잃었다.** 정지 출발 고속 gallop 52.7%(A' 72.3 · B' 74.7),
   상향 전환 11.2%(A' 43.8 · B' 33.2)로 다섯 중 가장 낮다. 하향 전환 86.1% 는 유지된다.
4. **(b) 는 σ 38 에서도 결정적 평균 경로로는 살아 있다** — 낙상 0, 고속 gallop 63.7%, 상향 29.2%, 하향 91.8%.
   그러나 떨림은 최악이다(8~25 Hz 0.90~0.96, 절대 파워 2848~2979 로 B' 의 12~21배). 확률적 경로는 미측정이다.
5. **(c) 67k 는 45k 와 거의 같다.** 고속 gallop 74.7→71.3, 상향 33.2→34.1, HF 0.422→0.449, `dof_pos` W1 0.054→0.052.
   측정 가능한 항목 중 뚜렷이 움직인 것은 σ 12.98→23.74 뿐이다. `other%` 도 올랐지만(고속 8.9→14.8)
   3' 절에서 그 열의 의미가 확정되지 않아 변화의 근거로 쓰지 않는다. **22k iter 를 더 돌려 바뀐 거동은 미확인이다.**
