## 왜 이 조합인가

`w_action_rate` 는 두 경로에서 서로 다른 물리량을 벌하고 있었다. 지지 다리의 `a_loc` 는
위치라서 `Δa` 가 속도지만, 조작 다리의 `a_man` 은 이미 증분이라 `Δa` 는 **가속도**다. 그래서
조작 다리에는 1차(속도) 페널티가 없었고, 목표가 일정 속도로 표류하는 비용이 0 이었다.
`w_joint_target_rate` 는 실제로 액추에이터에 보내는 관절 목표의 스텝당 변화량을 벌하므로 두
경로에 동일하게 걸린다.

페널티를 −4.0 까지 올릴 수 있었던 것은 `jvel_filter_alpha` 가 push 여유를 벌어줬기 때문이다.
필터 단독(`jvf_only`)은 떨림을 거의 줄이지 않는 대신 200 N push 를 +22.0%p 올린다. 그 여유를
페널티로 환전한 것이 이 run 이다. 자세한 5-arm 비교는
[`../../_comparisons/tremor_regularization_sweep/`](../../_comparisons/tremor_regularization_sweep/).

## DR ablation 이 말해 주는 것

1. **떨림은 전부 관측 노이즈 통과분이다.** 1.415 → 0.012 (−99.2%). 물리 DR 의 기여는
   0.012 → 0.002 로 미미하다. 정책 자체는 사실상 완전히 매끄럽다.
2. **앞선 로그에 "조작 다리 3.09°/step 의 미규명 기전이 남아 있다"고 적었던 것은 정정한다.**
   별도 기전이 아니라 그 다리의 **노이즈 감도가 높은 것**이었다. 노이즈를 끄면 0.02 로 사라진다.
3. **평균 오차 10.4 mm 는 노이즈로 설명되지 않는다.** 15.60 → 10.40 중 5.2 mm 만 DR 탓이고,
   나머지는 정책·기구학의 정상상태 오차로 남는다.
4. **push 는 세 조건이 구분되지 않는다** (150 N 76.5 / 76.7 / 74.3%, 오차범위 전부 겹침).
   밀려 넘어지는 것은 DR·노이즈 탓이 아니라 **능력 한계**다.
5. **궤적은 노이즈와 물리 DR 이 대략 반씩 기여한다** (19.72 → 16.71 → 13.76 mm).

⚠ DR-OFF 수치는 **배포 예상 성능이 아니라 정책 능력의 상한**이다. 실기 센서에도 노이즈가
있으므로 떨림은 실기에서 사라지지 않는다.
