그 과정에서 그 증상의 원인이 초기화가 아니라는 것이 드러났다.**

## 1. 학습 곡선 — 변화 없음, 그리고 그게 정상이다

| 구간 | reward | eplen |
|---|---|---|
| baseline 최근 200 iter | **42.02** | 975.5 |
| ft 초반 900 | 41.68 ± 0.95 | 967.5 |
| ft 중반 900 | 41.69 ± 0.98 | 968.8 |
| ft 최근 272 | 41.66 ± 0.99 | 966.7 |

세 구간 평균이 소수 둘째 자리까지 같고 추세는 −0.110 / 1000 iter — 표준편차의 1/9 이라 0 이다.
기준 대비 **−1.0 %** 가 노이즈를 넣은 비용의 상한이다.

⚠ 이 곡선은 판정에 쓸 수 없다. 노이즈는 보상 함수를 안 건드리고 초기 분포만 넓혔으므로,
reward 는 sim 초기분포 **전체 평균**이라 겨냥한 조건을 따로 보여주지 않는다.

## 2. 처짐 기동 프로브 — 겨냥한 것은 안 움직였다

`_workspace/hindleg_droop_start_probe.py`. 기존 두 프로브가 **앞 100 스텝을 버리는데** 이번
질문이 정확히 그 구간에 있어 새로 만들었다. 512 env · 1000 step · 종료 에피소드 약 520 개/명령.
초기 자세 `real_hip` = 08-28 실기 캡처 실측(HL +0.160 / HR −0.234), jitter ±0.05 rad.

### 2-a. 개시·낙상 (initial pose = real_hip)

| cmd | 개시 성공률 | 개시 지연(중앙) | 낙상률 |
|---|---|---|---|
| 0.3 | 97.7 % → 98.6 % | 0.22 → 0.26 s | 2.3 % → **1.2 %** |
| 0.5 | 98.1 % → 97.5 % | 0.20 → 0.28 s | 2.7 % → **1.7 %** |
| 1.0 | 98.7 % → 97.1 % | 0.36 → 0.38 s | 3.6 % → **2.3 %** |

개시는 **양쪽 다 이미 잘 된다** — 성공률 97~99 %, 차이는 이항 표준오차(±0.6 %) 안이다.
낙상률만 3/3 같은 방향으로 내려갔다(최대 1.7σ). 개별로는 유의하지 않고 방향만 일관된다.

### 2-b. ★hip 상태 — **차이가 없다**

| cmd | 관절 | q mean | 창끝(2 s) | 한계(±0.234) 밀착 |
|---|---|---|---|---|
| 0.3 | HL_hip | +0.1810 → +0.1802 | +0.2033 → **+0.2033** | 36.6 % → 33.4 % |
| 0.3 | HR_hip | −0.2544 → −0.2539 | −0.2562 → −0.2558 | **97.5 % → 97.3 %** |
| 1.0 | HL_hip | +0.1632 → +0.1723 | +0.1829 → +0.1768 | 30.6 % → 34.4 % |
| 1.0 | HR_hip | −0.2500 → −0.2501 | −0.2508 → −0.2502 | 92.3 % → 92.3 % |

창끝 값이 소수 넷째 자리까지 같다. **노이즈는 hip 이 한계에 붙는 것을 전혀 바꾸지 못했다.**

### 2-c. ★그리고 원인이 초기화가 아니다 — `default` 출발이 그 증거

같은 프로브를 **전 관절 0** 에서 출발시켜도 2 초 안에 같은 자리로 간다:

| cmd | 관절 | 시작 | q mean (base) | 창끝 (base) | 한계 밀착 (base) |
|---|---|---|---|---|---|
| 0.3 | HL_hip | 0.000 | +0.1560 | +0.2030 | 30.8 % |
| 0.3 | HR_hip | 0.000 | −0.2477 | −0.2561 | **93.9 %** |
| 1.0 | HR_hip | 0.000 | −0.2435 | −0.2501 | 89.0 % |

`real_hip` 출발(HR 밀착 97.5 %)과 `default` 출발(93.9 %)의 차이가 3.6 %p 뿐이다.
⇒ **hip 이 한계에 붙는 것은 처진 자세에서 시작해서가 아니라 정책이 그리로 몰기 때문**이다.
초기 상태 노이즈는 **겨냥한 변수가 틀렸다** — 초기화를 아무리 흔들어도 2 초면 같은 자리로 수렴한다.

★교차 확인: 08-28 실기 캡처에서 HR_hip 은 목표가 **100 % 하한 클램프**, HL_hip 은 **93.3 % 상한
클램프**였다. sim 이 이 현상을 그대로 재현한다(`|q|` 가 soft limit ±0.234 를 넘어 ±0.25 에 앉는
것은 hard limit 이 0.234/0.9 = 0.26 이기 때문이다). 실기 고유 문제가 아니라 **정책의 성질**이다.

### 2-d. 개시 창 토크 트립 — 개선 (thigh 단독)

채널 35 N·m / 50 ms, `real_hip` 출발. hip·calf·foot 은 양쪽 다 0 이라 thigh 만 움직였다.

| cmd | baseline | resetnoise |
|---|---|---|
| 0.3 | 22 | **12** |
| 0.5 | 20 | **10** |
| 1.0 | 10 | **4** |

3/3 모두 약 절반이다. `default` 출발에서는 6→6 · 8→5 · 10→8 로 약하다 ⇒ **처진 자세에서
출발할 때의 개시 구간에 한정된 이득**이고, 노이즈가 겨냥한 방향과 부합하는 유일한 양성 신호다.

## 3. 정상상태 트립 게이트 — 소폭 악화

`hindleg_trip_probe`, 앞 100 스텝 제외. 채널 35 N·m 총 트립 수:

| cmd | baseline | resetnoise |
|---|---|---|
| 0.3 | 3 | 12 |
| 0.5 | 3 | 12 |
| 1.0 | 2 | 8 |
| **합계** | **8** | **32** |

초과**율**은 거의 같다(예 calf cmd 0.5 0.029 % → 0.051 %). 절대 수가 워낙 작아 4 배라는 비가
과장돼 보이지만, 방향은 악화이고 `calf` 가 0 → 8 (cmd 0.5) 로 새로 뚫린 셀이 생겼다.
속도 달성률·토크 통계는 실질적으로 동일하다(달성률 91/93/92 % → 91/93/91 %).

## 4. 판정

| 항목 | 결과 |
|---|---|
| 학습 비용 | reward −1.0 % — 무시할 만함 |
| 개시 성공/지연 | 차이 없음 (양쪽 다 97~99 %) |
| 낙상률 | 3/3 하락, 개별 유의성 없음 |
| **hip 한계 밀착 (겨냥한 증상)** | **변화 없음** |
| 개시 창 트립 (처짐 출발) | 22/20/10 → 12/10/4 — **일관된 개선** |
| 정상상태 트립 | 8 → 32 — 소폭 악화 |

**노이즈는 무해하고 개시 구간에 국소적 이득이 있으나, 겨냥한 hip 처짐은 못 고쳤다.**
`gainclamp_ft/model_39799` 를 배포 후보에서 내릴 근거는 없다.

★가장 중요한 산출물은 A/B 결과가 아니라 **§2-c** 다 — hip 한계 밀착의 원인이 초기 자세가
아니라는 것. 이 저장소가 한 번 겪은 실패 양식과 같다(`project_leg_rsi_match_command_is_init_artifact`:
"설계가 아니라 겨냥한 변수가 틀림").

   초기화는 이 증상의 원인이 아니다.
