# Session: 2026-04-06 — Go2 WTW LCP Gradient Penalty 버그 원인 분석 및 수정 + 간략화

## 업데이트된 Agent
- **rl-debug-worker**: requires_grad 위치 확인 규칙, gradient penalty 발산+entropy 동시 증가 패턴 진단 규칙 추가
- **loss-worker**: 기존 4개 규칙 Deprecated 처리, 최종 구현(obs_batch_gp TensorDict leaf tensor 직접 미분) 1개 규칙으로 통합
- **global_lessons**: flat tensor vs TensorDict 이식 규칙 + TensorDict + torch.cat = silent graph break 패턴 추가

## 핵심 발견
1. `cat([o_norm, z]).requires_grad_(True)` → z가 독립 변수로 취급 → actor가 priv_latent 무시 → task reward 저하
2. L_GP ∝ 1/σ² 이므로 σ 증가로 penalty 회피 가능 → gradient penalty 발산 + entropy 증가가 동시에 나타나는 수학적 원인
3. flat tensor `obs_batch.requires_grad_()` → TensorDict 구조 이식 시 leaf variable 위치가 달라지는 silent bug
4. `get_actor_obs()`는 내부적으로 `torch.cat(obs_list)`를 호출해 매번 새 tensor 인스턴스 생성 → gradient target으로 재사용 불가. 올바른 gradient target은 `obs_batch_gp[group]` (leaf tensor 자체)

## GP 최종 구현 (ppo_parkour.py)
```python
obs_batch_gp = obs_batch.clone().apply(lambda x: x.requires_grad_(True) if isinstance(x, torch.Tensor) else x)
self.policy.act(obs_batch_gp, ...)
actions_log_prob_batch = self.policy.get_actions_log_prob(actions_batch)
# ...PPO losses...
policy_tensors = [obs_batch_gp[g] for g in self.policy.obs_groups["policy"]]
grads = torch.autograd.grad(actions_log_prob_batch.sum(), policy_tensors, create_graph=True)
gradient_penalty_loss = torch.stack([g.square().sum(-1).mean() for g in grads]).sum()
```
