## 반려된 분석 요약

| 가설 | 반려 이유 |
|------|----------|
| 모션 데이터 분포 편향 (중앙값 1.5m/s) → Discriminator 고속 학습 불가 | MimicKit도 랜덤 명령에서 잘 됨, 데이터 부족이 "아예 안 움직임"의 이유 불충분 |
| action_scale=0.25 × [-1,1] → ±0.25 rad 물리적 한계 | GaussianMixin + clip_actions=False → output unbounded, 근거 자체 틀림 |
| task reward × step_dt → style reward 대비 극소화 | config에서 lin_vel_reward_scale = 1.0/step_dt로 이미 보정 중 |
| tracking_sigma=0.25 엄격 → 고속에서 gradient 소실 | sigma 크면 local minima 위험, 단순 trade-off는 설득력 없음 |
| 추진력 없음 = contact reward 부재 | MimicKit도 contact reward 없음 |
