## 참고 / 주의
- **GPU 2번만** 사용(`CUDA_VISIBLE_DEVICES=2`). 학습+play 공존 OK(24GB).
- **측방(vy)·베이스높이 조종 안 됨**: 정책이 vy=0으로 학습·높이 명령 자체 없음. 원하면 cfg `lin_vel_y_range`를 [-0.5,0.5]로 바꿔 **재학습**(전방향 정책).
- **화살표**: play.py가 `set_debug_vis` 자동 호출 → 로봇 위 초록(명령)·파랑(실제). 학습(headless)엔 무영향.
- **알려진 함정**(설치/재현): EULA=`OMNI_KIT_ACCEPT_EULA=YES` / rsl_rl fork editable설치 / cuDNN cu13→cu12 재설치 / play는 pandas 필요 / play는 `--video_length` 크게 안하면 200스텝서 종료. 상세=메모리 gpu-server-hindleg-rl.
- WebRTC 검은화면 시: play/client 여러 재시작으로 꼬인 상태 → `hindleg_teleop.sh stop` 후 다시 시작(클린).
